# F1R3FLY Brand Fonts

Two free Google Fonts do all the typing in the F1R3FLY system. Download and install
(Mac: double-click → "Install Font"; Windows: right-click → "Install") so F1R3FLY
materials render correctly. Both are also available inside Canva, Google Docs and
Slides, Figma, and any web page via the Google Fonts links below.

## The system (updated 2026-09-20)

| Font | Role | Weights in the system | Get it |
|------|------|-----------------------|--------|
| **League Spartan** | Headings, eyebrows, subheaders, UI text. Replaced Josefin Sans on 2026-09-20. | Light 300, Regular 400, SemiBold 600, Bold 700 | The four TTFs in this folder, or [Google Fonts](https://fonts.google.com/specimen/League+Spartan). Free, SIL Open Font License |
| **Source Sans 3** | Body copy, supporting text | Light 300, Regular 400, Bold 700 | The three TTFs in this folder, or [Google Fonts](https://fonts.google.com/specimen/Source+Sans+3). Free, SIL OFL. (Google renamed it from Source Sans Pro; same face.) |
| **Brandon Grotesque** | Logo lockups only, outlined inside the logo files | none | Not in this repo and never typed. If you need the wordmark, use a logo file |

**Web embed:**
`https://fonts.googleapis.com/css2?family=League+Spartan:wght@300;400;600;700&family=Source+Sans+3:wght@300;400;700&display=swap`

**Rules:** League Spartan for anything you type as a heading or label, Source Sans 3 for
body, never retype Brandon Grotesque. Only the four League Spartan weights above are in
the system; do not use Thin, ExtraLight, Medium or Black. **Josefin Sans is retired.**

**Canva note:** Canva's built-in League Spartan is an old single-weight cut. Upload the
four TTFs from this folder to your Brand Kit (Brand → Fonts → Manage uploaded fonts) and
use those.

The distributed templates in `/templates/` have Brandon display text converted to
outlines, so they render correctly even without any fonts installed.
